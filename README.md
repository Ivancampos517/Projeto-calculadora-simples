# Calculadora Simples em C

Projeto de faculdade/estudo: uma calculadora de linha de comando escrita em C, feita para praticar lógica de programação e operações matemáticas básicas.

## Como compilar e rodar

```bash
gcc Projeto/calculadora.c -o calculadora
./calculadora
```

## Sobre

Este projeto faz parte dos meus estudos em programação, com foco em fixar os conceitos básicos da linguagem C (entrada e saída, operadores, estruturas condicionais).
